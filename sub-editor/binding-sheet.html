Binding Sheet

Every server action and state path the Sub Editor's autocomplete actually knows about, rendered straight from sub-editor/server-bindings.js - the same file editor.js loads, so this page can never drift out of sync with what the Binding/State Binding fields will actually accept. See Help & Docs → Bindings & Payload Keys for what these fields mean and how they're used.

bool fields: a Visual State's Name must be the exact string true or false (lowercase, no quotes typed in the field itself) to match a boolean value - never T, 1, or on. For a Rotate/Linear Output's Value Min/Max, use the plain numbers 0 and 1 - a JS boolean behaves as 0/1 automatically in that math, so Min=0/Max=1 always works. A Texture Swap output needs no range at all: it just checks the raw value directly. See Help & Docs → Visual States and → Texture Swap.
